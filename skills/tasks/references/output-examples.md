# Формат вывода: примеры

> Вынесено из skills/tasks/SKILL.md (issue #134, progressive disclosure).

## При создании ≤ 3 задач (без checkpoint)

```
═══════════════════════════════════════════
ЗАДАЧИ СОЗДАНЫ
═══════════════════════════════════════════

Из: FEAT-001 (Добавить экспорт в PDF)
Создано задач: 3

ГОТОВЫ К РАБОТЕ:
   • TASK-001: Создать сервис экспорта [P1]
   • TASK-002: Добавить UI кнопку [P1]

ЖДУТ ЗАВИСИМОСТИ:
   • TASK-003: Интеграционные тесты [P2]
     (ждёт: TASK-001, TASK-002)

═══════════════════════════════════════════
СЛЕДУЮЩИЙ ШАГ:
   → /polisade:implement TASK-001 — начать реализацию
   → /polisade:continue — автономная работа
═══════════════════════════════════════════
```
